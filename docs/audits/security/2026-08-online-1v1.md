## Known limitations (accepted for launch)

1. **guestId is client-supplied** — a hostile client can claim another guest's id. Session tokens are per-connection; no account/credential value is at stake (guests hold no persistent state beyond a nickname). Revisit if profiles/stats are added.
2. **No per-IP cap on Quick Match joins** — queue cap + socket-level rate limit bound impact. Add IP throttle if queue abuse appears.
3. **Rematch seat order does not rotate** (spec FR-9 said swap; current keeps seats, reseeds map). Trivial follow-up if desired.
4. **Ping measurement is client-observed** (`ping/pong` RTT); server does not validate it. Display-only.
