<h1 class="docs-h1"><span>NEON</span> VOID // MANUAL</h1>
<p class="docs-lead">
Same keyboard. Two pointers. First to <strong>5 wins</strong> takes the void. No bots, no ELO — guest only.
60s rounds on a 24×14 grid (<code>960×560, GRID 40</code>). Built with SVG, 60fps fixed step.
</p>

<div class="docs-grid">
  <div class="docs-card docs-card--cyan">
    <div class="docs-kicker"><i>01</i> CORE LOOP</div>
    <h3 class="docs-h3">DUEL → ORB → HAZARD → VOID</h3>
    <p class="docs-p">Spawn at <code>140,280</code> / <code>820,280</code>. Move, dash, shoot. Grab orbs. Avoid lava/slime/void. Round ends on elimination or HP advantage at <code>60s</code>. First to 5 wins the match.</p>
  </div>
  <div class="docs-card docs-card--lime">
    <div class="docs-kicker"><i>02</i> START</div>
    <h3 class="docs-h3">MENU → COUNTDOWN → FIGHT</h3>
    <p class="docs-p"><strong>START DUEL</strong> resets <code>scores 0//0 round 1</code>, rebuilds walls, <code>countdown 3→2→1→FIGHT</code> (<code>650ms</code> ticks). <code>EXIT</code> per player forfeits instantly to menu.</p>
  </div>
</div>

<div class="docs-grid">
  <div class="docs-card docs-card--lime">
    <div class="docs-kicker"><i>08</i> ROUNDS & WIN</div>
    <h3 class="docs-h3"><code>ROUND_TIME 60</code> • FIRST TO 5</h3>
    <ul class="docs-list">
      <li>Elimination → <code>scores[winner]++</code> + <code>endRound</code> <code>ROUND X</code> → <code>1.6s</code> next round.</li>
      <li>Time up → HP advantage wins, else <code>DRAW</code>.</li>
      <li><code>WIN_SCORE 5</code> → <code>showGameOver</code> <code>1.4s</code> (<code>1.8s</code> forfeit).</li>
      <li>Forfeit (<code>EXIT</code> or <code>nox:forfeit</code>) → opponent <code>5</code> + <code>FORFEIT // P X EXIT → P Y WINS</code>, 1.8s + <code>CONTINUE // PLAY AGAIN</code>.</li>
    </ul>
  </div>
